# refactoring

指示されたコードベースに対して、クリーンコードの原則に基づいたリファクタリングを実施します。特に、複雑な条件分岐の解消、重複コードの排除、および最新の言語機能（C++20, Python 3.12, C# 12など）への適合に注力します。

## Usage

以下のような状況で使用します：
- メソッドやクラスが肥大化し、ロジックの把握が困難になったとき。
- 「マジックナンバー」や「コピペコード」が散見されるとき。
- パフォーマンス向上やメモリ使用量（VRAM等）の最適化が必要なとき。
- テストコードを書きやすくするために、依存関係を切り離したいとき。

## Steps

1. **現状分析と意図の把握**: 既存コードの入出力と副作用を特定し、リファクタリング後も動作が変わらないことを保証するための境界を確認します。
2. **小規模な分解 (Decomposition)**: 巨大な関数を小さな論理単位に分割し、適切な命名（動詞+名詞）で関数化します。
3. **ガード節の導入**: 入れ子になった `if` 文を「ガード節」に置き換え、正常系のロジックをメインストリームに配置してネストを浅くします。
4. **型の最適化とモダン化**: 
    - C++: 生ポインタをスマートポインタへ、`std::vector` の予約による再確保の抑制。
    - Python: `typing` による型ヒントの追加、リスト内包表記への置換。
    - C#: `record` 型の活用や、LINQによる宣言的な記述への変換。
5. **DRY原則の適用**: 重複しているロジックを共通クラスやユーティリティ関数に集約します。
6. **検証**: 修正後のコードが元の仕様を満たしているか、シンタックスエラーがないか、パフォーマンスが劣化していないかを最終確認します。
