# test-validator

## Usage
- 新機能の実装前後でデグレを防ぎたいとき。
- pytest (Python) や MSTest/NUnit (C#) のテストコードを生成したいとき。

## Steps
1. **パス解析**: 正常系、異常系、境界値（Boundary cases）の実行パスを抽出します。
2. **モック作成**: 外部API（LLM APIなど）やファイルI/Oをモック化し、テストを分離します。
3. **テスト実装**: 言語標準のフレームワークを用いてテストケースを記述します。
4. **カバレッジ確認**: 未テストの条件分岐がないかチェックし、追加のテスト案を提示します。
