# data-analyzer

## Usage
- CSV/JSONデータのクレンジングが必要なとき。
- 投資データの時系列分析やモンテカルロシミュレーションのロジックを組むとき。

## Steps
1. **スキーマ確認**: 入力データの列名と型を把握します。
2. **ベクトル演算**: `for` ループを避け、pandas/numpy のベクトル演算に置き換えて高速化します。
3. **インタラクティブ可視化**: Plotlyなどを用いて、動的なグラフ生成コードを記述します。
