# Code Sentinel

## 概要
このアプリケーションは、指定されたコードベース（Python, C++, C#, JSONなどのファイル）を対象に、Retrieval-Augmented Generation (RAG) を利用したコード検索および質問応答システムを提供します。ローカルで動作する大規模言語モデル (LM Studio互換) と連携し、開発者がコードに関する質問をしたり、関連するコードスニペットを効率的に見つけたりするのを支援します。

## 特徴
- **RAGによるコード検索**: 指定されたディレクトリ内のコードファイルから関連情報を抽出し、質問に対する回答を生成します。
- **NiceGUIによる直感的なWeb UI**: ブラウザベースのシンプルなインターフェースで、コードの検索とプレビューが可能です。
- **LM Studioとの連携**: ローカルで動作するLM Studioを通じて、オフライン環境でも大規模言語モデルを利用できます。
- **リアルタイムシステム監視**: CPUとRAMの使用率、LM Studioの接続状態をリアルタイムで表示します。
- **設定可能なターゲットディレクトリ**: コードベースの検索対象ディレクトリをUIから簡単に設定・保存できます。

## インストール方法
1. Python 3.xをインストールします。
2. 必要なPythonライブラリをインストールします。
   ```bash
   pip install -r requirements.txt
   ```
   (または、`CodeSentinel.py`に記載されているライブラリを手動でインストールします: `os`, `sys`, `asyncio`, `psutil`, `httpx`, `pathlib`, `nicegui`, `langchain-core`, `langchain-openai`, `langchain-community`, `langchain-text-splitters`)
3. LM Studioをダウンロードし、インストールします。
4. LM Studioで互換性のある大規模言語モデルをダウンロードし、サーバーを起動します (デフォルトのポートは`1234`)。

## 使い方
1. `CodeSentinel.py`を実行します。
   ```bash
   python CodeSentinel.py
   ```
2. ブラウザでアプリケーションにアクセスします (通常は `http://localhost:8080`)。
3. 左側のサイドバーから「SET」タブを選択し、コードベースのパスを設定して「SAVE PATH」をクリックします。
4. 「REBUILD」ボタンをクリックして、ベクトルストアを構築または再構築します。
5. 画面下部の入力フィールドに質問を入力し、「Send」ボタンをクリックすると、RAGによって生成された回答と関連コードが表示されます。
6. 検索結果として表示されるファイル名をクリックすると、そのファイルの内容をプレビューできます。

## 設定
- **ターゲットディレクトリ**: サイドバーの「SET」タブで、RAGの対象となるコードベースのディレクトリパスを変更できます。

## 技術スタック
- **フロントエンド**: NiceGUI
- **RAGフレームワーク**: LangChain
- **ベクトルストア**: FAISS
- **HTTPクライアント**: httpx
- **システム監視**: psutil
- **大規模言語モデル**: LM Studio (OpenAI互換API)
