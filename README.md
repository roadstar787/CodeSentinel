# CodeSentinel (v1.5.0)

## 概要
CodeSentinel は、Retrieval-Augmented Generation (RAG) を活用した、エンジニアのための高度なコード分析・質問応答システムです。
ローカルのコードベースと仕様書（PDF, Markdown, Excel 等）を横断的に検索し、実装と仕様の乖離を特定する「ギャップ分析」や、AIによる修正案の提示・自動適用機能を提供します。
オフライン環境（LM Studio 互換サーバー）での動作を前提としており、機密性の高いプロジェクトでも安心して利用できます。

## 主な機能

### 1. ギャップ分析 (Gap Analysis) & AI修正 🚀 New in v1.5.0
- **仕様と実装の比較**: 仕様書（DOCS）とソースコード（CODE）の内容を比較し、矛盾点や未実装項目を自動的に抽出します。
- **AIコード修正 (FIXボタン)**: 指摘された箇所に対し、AIが具体的な修正案を提示します。「FIX」ボタンから直接ファイルを更新可能です。
- **安全な適用**: ファイル更新前に日本語の確認ダイアログが表示され、不完全なコード（スニペット）による破壊を防ぐための警告も備えています。

### 2. 高度なコードプレビュー & 比較 UI
- **2カラム表示**: 行番号とコードを分離して表示し、高い視認性を維持します。
- **修正案の比較**: プレビュー画面右上のトグルスイッチで「ORIGINAL（現状）」と「AI SUGGESTION（修正案）」を瞬時に切り替えて比較できます。
- **全文検索 & ジャンプ**: プレビュー内でのワード検索、Enter キーによる次候補巡回、および指定行へのジャンプに対応。

### 3. ハイブリッド RAG 検索
- **マルチドキュメント対応**: `.py`, `.cpp`, `.cs`, `.h`, `.json` などのコードに加え、`.pdf`, `.md`, `.xlsx`, `.pptx` などのドキュメントをサポート。
- **依存関係の自動検知**: Excel 等の読み込みに必要なライブラリが不足している場合、適切なインストール方法を自動的にアドバイスします。

### 4. 堅牢なパースロジック & ユニットテスト
- **不完全JSONの修復**: AIの回答が途中で途切れた場合でも、プログラムが自動的にJSON構造を補完してパースを完遂します。
- **包括的なテスト**: バックエンド、UIパース、ファイル操作に対するユニットテストが完備されています。

## インストール方法

### 推奨環境: uv を使用する場合
```bash
# 依存関係を同期
uv sync
```

### pip を使用する場合
```bash
pip install -r requirements.txt
pip install pytest nicegui  # テスト実行・UI用
```

## 使い方

1. **LM Studio の準備**
   - [LM Studio](https://lmstudio.ai/) を起動し、Local Server を開始（Port 1234）。

2. **起動**
   ```bash
   # uvの場合
   uv run python CodeSentinel.py
   # pipの場合
   python CodeSentinel.py
   ```

3. **テストの実行**
   ```bash
   # 全ユニットテストの実行
   uv run python -m pytest
   ```
